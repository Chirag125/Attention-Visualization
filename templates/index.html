Residual Stream — Layer Contribution per Token

How much each layer CHANGES each token's representation (L2 norm of hidden state delta). Hot = layer is actively processing that token. Cool = residual connection dominates (pass-through).


Attention Head Entropy

Shannon entropy per head. Low entropy = focused head (tracks specific relationships). High entropy = diffuse/uniform attention = head may be inactive. Rows = layers, Columns = heads.


Integrated Gradients — Token Importance

True token importance via gradient attribution (Sundararajan et al. 2017). Unlike attention weights, this measures how much changing each input token would actually affect the [CLS] output representation.
